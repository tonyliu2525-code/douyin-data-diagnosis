# Douyin Data Diagnosis

基于一套抖音数据分析口播方法，诊断单条口播作品的观看路径、流量来源和账号承接。

## 使用方式

进入诊断后，默认只需要当前作品的三张后台截图：

1. 作品数据概览；
2. 完整观众留存曲线；
3. 完整流量来源；

再附上封面、标题和前 15 秒的作品内容。详细截图路径见 [三图一作品采集说明](references/screenshot-intake.md)。

需要诊断整个账号周期时，按 [账号周期两阶段采集说明](references/account-cycle-intake.md) 先提供账号总览和周期作品列表，再选择代表作品补充单条数据。

## 方法边界

- 2 秒跳出率和 5 秒完播率必须联动分析；
- 不用单条完播率判断内容价值；
- 不输出没有来源的平台阈值；
- 不将搜索、主页访问或播放量直接等同于客户或成交；
- 只在同账号、相近时长、相同观察窗口和投流条件相近的样本间做相对比较。

完整规则见 [SKILL.md](SKILL.md)。
