# 诊断报告格式

## 1. 诊断范围与数据质量

- 诊断对象：
- 观察窗口：
- 样本数：
- 自然流/投流状态：
- 可比组：
- 已提供数据及来源：
- 缺失字段及其限制：

## 2. 指标计算表

逐条列出：播放量、时长、平均播放时长、平均播放占比、2 秒跳出率、5 秒完播率、2 秒存活率、2→5 秒相对留存、2→5 秒相对流失、完播率、封面点击率、搜索、个人主页、推荐来源。

数据齐全时，另列“5 秒后人群估算平均观看时长”，并在列名和段落中注明使用了原稿的 1 秒、3.5 秒假设。

若字段缺失，写“未提供”，不得填零。

## 3. 作品观看诊断

按原方法顺序写：

1. 平均播放时长与平均播放占比；
2. 2 秒与 5 秒的联动结果；
3. 封面主动选择；
4. 完播率的补充意义。

每条结论标注：`事实 / 计算结果 / 有条件推断 / 无法判断`。

## 4. 流量来源诊断

依次说明搜索、个人主页、推荐及其他来源。区分“来源播放”和“主页访问”。没有搜索词时，不对用户需求下结论。

## 5. 账号承接诊断

说明主页访问、播放、关注和互动之间的关系。没有账号页数据时，明确无法诊断账号承接。

## 6. 考评标准

- 存在同账号、同观察窗口、时长和流量条件相近的可比组：列出中位数与相对位置，如“高于本组中位数”。
- 没有可比组：只写“暂无评分线”，不虚构 A/B/C 或平台阈值。
- 需要稳定标准：持续按同一口径保留历史样本，并按时长、投流、来源构成分组后建立账号基线；本 Skill 不规定样本条数门槛。

## 7. 下一步验证

只提出一个下一轮变量，说明：要改什么、为何由当前数据支持、下一次需要观察哪些数据。

## 8. 不能下的结论

明确列出当前不能从数据推出的内容，例如“不能仅凭 2 秒跳出判开头失败”“不能仅凭搜索占比判精准客户”“不能仅凭播放判账号价值”。
